# پلتفرم هوشمند همسفری و نقشه (Nimrah Project)

این پروژه یک پلتفرم پیشرفته وب‌محور برای مسیریابی، اشتراک‌گذاری سفر (همسفر)، مدیریت ایستگاه‌های مردمی، و گفتگوی گروهی (موقت و دائمی) است که با الهام از سرویس‌های نقشه بومی طراحی و توسعه داده شده است. رابط کاربری این پروژه با پشتیبانی کامل از زبان فارسی و جهت راست‌به‌چپ (RTL) بهینه‌سازی شده است.

---

## 📋 دامنه پروژه (Project Scope)
دامنه این پروژه شامل ایجاد یک اکوسیستم کامل حمل‌ونقل شهری و حومه‌ای است که در آن کاربران می‌توانند علاوه بر مسیریابی معمولی معابر، با افراد هم‌مسیر ارتباط برقرار کرده، هزینه‌های رفت‌وآمد را به اشتراک بگذارند، ایستگاه‌های تاکسی/اتوبوس محلی ثبت کنند و گروه‌های ارتباطی دائمی تشکیل دهند.

---

## 🚀 قابلیت‌های پیاده‌سازی شده در نسخه MVP
در نسخه اولیه (MVP) این پلتفرم، امکانات کلیدی زیر به صورت کامل پیاده‌سازی و تست شده‌اند:

1. **سیستم نقشه و مسیریابی (Routing & Map):**
   - مسیریابی خودرو، موتور و پیاده با استفاده از موتور OSRM.
   - محاسبه سریع‌ترین زمان و کمترین هزینه سفر.
   - امکان نمایش گام‌به‌گام دستورالعمل‌های مسیر (Turn-by-turn).
   - ابزار انتخاب نقطه روی نقشه (Pin Dropping) و تشخیص موقعیت مکانی از طریق GPS.
   - ذخیره مکان‌های شخصی (خانه، محل کار و سایر مکان‌ها).

2. **سیستم همسفر (Hamsafar & Live Matching):**
   - جستجوی زنده همسفران و گروه‌های هم‌مسیر بر اساس مبدا، مقصد و زمان (سفر آنی یا برنامه‌ریزی‌شده در آینده).
   - ارسال، قبول یا رد درخواست‌های همسفری با به‌روزرسانی زنده وضعیت.
   - چت گروهی موقت بین همسفران متصل‌شده.

3. **مدیریت گروه‌ها (Permanent Groups & Chat):**
   - قابلیت تبدیل گروه‌های موقت همسفری به گروه‌های دائمی با یک کلیک.
   - امکان مدیریت اعضا (توسط مالک گروه)، تغییر نام گروه، به اشتراک‌گذاری لینک دعوت، و ترک یا انحلال گروه.
   - ارسال پیام، فایل و تعاملات گروهی.

4. **ایستگاه‌های مردمی (Community Stations):**
   - امکان ثبت ایستگاه‌های حمل‌ونقل جدید (تاکسی، اتوبوس و غیره) با تعیین کرایه و ساعات حضور روی نقشه.

5. **پنل مدیریت مجزا (Admin Panel):**
   - پنل امن در مسیر مستقل (`/admin.html`) برای نظارت بر کل سیستم.
   - آمار کلی پلتفرم (تعداد کل کاربران، مسافران آنلاین، گروه‌ها و ایستگاه‌ها).
   - قابلیت مدیریت و مسدودسازی کاربران یا انحلال گروه‌های متخلف.

## 🛠️ تکنولوژی‌ها و فریم‌ورک‌های استفاده شده (Tech Stack)

- **فرانت‌اند (Frontend):**
  - React (برای ساخت کامپوننت‌ها و مدیریت ساختار)
  - Leaflet.js (کتابخانه قدرتمند نقشه‌های تعاملی)
  - Tailwind CSS (برای طراحی ریسپانسیو و استایل‌دهی)
  - FontAwesome (آیکون‌ها)

- **بک‌اند (Backend):**
  - FastAPI (فریم‌ورک مدرن و سریع پایتون برای ساخت API)
  - SQLAlchemy (مدیریت ارتباط با پایگاه داده و ORM)
  - SQLite (پایگاه داده سبک و محلی برای ذخیره‌سازی اطلاعات)

- **ابزارها و استقرار (Deployment):**
  - Docker & Docker Compose (برای کانتینرسازی و اجرای یکپارچه پروژه)
  - Uvicorn (سرور ASGI برای اجرای FastAPI)

## ⚙️ راهنمای راه‌اندازی و اجرای پروژه (Run Locally)

برای اجرای پروژه روی سیستم محلی خود، مراحل زیر را دنبال کنید:

### ۱. کلون کردن مخزن و ورود به پوشه پروژه
```bash
git clone <repository-url>
cd travel_map_project
```

### ۲. راه‌اندازی و اجرای بک‌اند (Backend)
ابتدا وارد پوشه بک‌اند شوید، محیط مجازی پایتون را بسازید و وابستگی‌ها را نصب کنید:
```bash
cd backend
python -m venv .venv
# فعال‌سازی محیط مجازی در ویندوز (PowerShell):
.venv\Scripts\Activate.ps1
# فعال‌سازی محیط مجازی در مک/لینوکس:
# source .venv/bin/activate

pip install -r requirements.txt
```
سپس سرور FastAPI را روی پورت `3000` اجرا کنید:
```bash
cd app
uvicorn main:app --port 3000 --reload
```
*(سرور روی آدرس `http://127.0.0.1:3000` آماده به کار خواهد بود).*

### ۳. راه‌اندازی و اجرای فرانت‌اند (Frontend)
در یک ترمینال جدید، وارد پوشه فرانت‌اند شوید، پکیج‌ها را نصب و سرور توسعه را اجرا کنید:
```bash
cd frontend
npm install
npm run dev
```
*(فرانت‌اند معمولاً روی آدرس `http://localhost:5173` اجرا می‌شود).*

## 👥 دسترسی به پنل مدیریت (Admin Access)
برای تست پنل مدیریت:
1. ابتدا از طریق پورت فرانت‌اند (`http://localhost:5173`) با شماره موبایل دلخواه خود (مثلاً `09111234567`) ثبت‌نام یا ورود کنید.
2. این شماره به‌طور پیش‌فرض در لیست مدیران سیستم (`ADMIN_PHONES`) در فایل بک‌اند تعریف شده است و سطح دسترسی `admin` را دریافت می‌کند.
3. سپس برای ورود به پنل، به آدرس زیر مراجعه کنید:
   `http://localhost:5173/admin.html`
