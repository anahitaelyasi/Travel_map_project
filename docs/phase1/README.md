# مستندات فاز اول پروژه (Phase 1 Documentation)

این پوشه شامل مستندات اولیه، تحلیل نیازمندی‌ها، طراحی‌های اولیه رابط کاربری و نسخه‌های اولیه محصول قابل ارائه (MVP) برای پلتفرم هوشمند همسفری و نقشه (Nimrah) است. هدف از این فاز، تعریف ساختار کلان سیستم، تعیین داستان‌های کاربر (User Stories) و پیاده‌سازی زیرساخت‌های اصلی فنی بوده است.

## 📁 ساختار مستندات و پوشه‌های این فاز

محتویات اصلی این فاز به شرح زیر است:

1. **پوشه `mvp/` (نسخه اولیه محصول):**
   - شامل کدهای اجرایی کامل فرانت‌اند (React) و بک‌اند (FastAPI) برای ارائه یک نسخه عملیاتی از پلتفرم با قابلیت‌های کلیدی نقشه، مسیریابی، همسفر، گروه‌های دائمی و پنل مدیریت مجزا.

2. **فایل `User_story2.pdf` (داستان‌های کاربر):**
   - شامل مستندات رسمی تحلیلی و Agile مربوط به نیازمندی‌های کاربران، معیارهای پذیرش (Acceptance Criteria)، سطح اولویت‌بندی قابلیت‌ها (MoSCoW) برای بخش‌های نقشه، مسیریابی، پروفایل، همسفر و گروه‌ها.

3. **فایل `figma_design.md` (طراحی‌های فیگما):**
   - حاوی لینک‌ها و توضیحات مربوط به طرح‌های اولیه رابط کاربری (UI/UX) و وایرفریم‌های پیاده‌سازی شده در نرم‌افزار Figma برای هماهنگی بین ظاهر بصری و کدنویسی فرانت‌اند.

---

## 🎯 اهداف و خروجی‌های فاز ۱

- **تحلیل و طراحی نیازمندی‌ها:** تدوین دقیق User Storyها برای سناریوهای مختلف کاربری (مسافر، راننده و مدیر).
- **طراحی رابط کاربری (UI/UX):** استفاده از الگوهای بصری استاندارد نقشه‌های بومی و تطبیق کامل با ساختار راست‌به‌چپ (RTL).
- **پیاده‌سازی MVP:** توسعه نسخه اولیه تمام‌استک (Full-Stack) با استفاده از React و FastAPI و پایگاه داده SQLite جهت تست و ارزیابی زنده قابلیت‌ها.
